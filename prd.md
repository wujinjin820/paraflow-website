## 模块：Built for every role

本模块用于在首页或产品介绍页展示不同角色的价值主张，包含标题区和 6 个角色卡片，深色背景、高对比度排版。

---

### 设计 Token（可在设计系统 / CSS 变量中维护）

```css
:root {
  /* 颜色 */
  --color-bg-body: #000000;
  --color-bg-card: #0d0d0d;
  --color-border-card: #1e1e1e;
  --color-text-primary: #f5f5f5;
  --color-text-secondary: #9a9a9a;
  --color-text-muted: #b0b0b0;
  --color-focus-ring: #3a82f7;

  /* 圆角 */
  --radius-card: 16px;
  --radius-icon: 12px;

  /* 间距 */
  --space-section-y: 48px;
  --space-section-gap: 32px;
  --space-card-padding: 28px;
  --space-card-gap-x: 20px;
  --space-card-gap-y: 24px;

  /* 字体 */
  --font-serif: "Playfair Display", "Times New Roman", serif;
  --font-sans: system-ui, -apple-system, BlinkMacSystemFont, "SF Pro Text",
    "Helvetica Neue", Arial, sans-serif;
}
```
